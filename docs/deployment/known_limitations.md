# Known Limitations

Current limitations:

- CNN baseline depends on available dataset quality.
- Dataset distribution may still be imbalanced.
- YOLOv8 detection is pending because bounding-box annotations are not yet available.
- YOLOv8-Seg segmentation is pending.
- MiDaS/depth estimation is not yet fully integrated.
- Measurement values are prototype/mock unless real depth estimation is implemented.
- Offline queue does not yet support full background synchronization.
- Physical Android device requires correct LAN API URL.
- Production deployment requires security hardening.

Do not claim unfinished features as final.
