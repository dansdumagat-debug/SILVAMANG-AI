# SILVAMANG AI Testing Evidence

This folder contains the testing plan, test case templates, evaluation evidence templates, API testing assets, and defense evidence checklist for SILVAMANG AI.

No results in this folder should be treated as completed unless the `actual_result`, `status`, or summary fields are filled from real test execution.

## Contents

- `test_plan.md` - formal test plan
- `*_test_cases.csv` - functional, API, mobile, and admin test case templates
- `ai_evaluation_summary.md` - AI/CNN evidence summary
- `usability_evaluation_form.md` - participant form template
- `requirements_traceability_matrix.csv` - requirements-to-test mapping
- `api/` - endpoint documentation and Postman collection
- `evidence/` - screenshots, reports, and logs
- `scripts/` - lightweight evidence helper scripts
